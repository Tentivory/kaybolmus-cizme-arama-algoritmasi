# Kaybolmuş Çizme Arama Algoritması

## Resmi Açıklama

Bu proje, insanlığın en büyük sorunlarından birini çözmek için geliştirilmiştir: **Kaybolmuş çizmeleri bulmak.**

Algoritma, tamamen rastgele koordinatlar üreterek "burada olabilir" der. Hiçbir zaman doğru çıkmaz ama çok bilimsel görünür.

## Kullanım

```bash
python3 cizme_ara.py
```

Örnek çıktı: "Çizmeniz 41.015137, 28.979530 koordinatlarında olabilir. Ya da olmayabilir."
